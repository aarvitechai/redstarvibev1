# RedStarVibe

Photo and video social platform: posts, stories, reels, chat, audio and video calls, AI features and an MCP server.
Architecture: [docs/RedStarVibe_Technical_Architecture.md](docs/RedStarVibe_Technical_Architecture.md).
What is done and what is not: [docs/STATUS.md](docs/STATUS.md).

## Run it locally

You need Docker Desktop and Python 3.

```bash
python scripts/bootstrap_env.py     # creates .env with fresh secrets
make up                             # builds and starts everything
make seed                           # demo users and posts
```

| What | Where |
|---|---|
| App | http://localhost:8080 |
| Demo login | `demo` / `RedStarDemo#2026` (also `asha`, `kabir`, `meera`, `rohan`). `demo` is an admin. |
| Emails sent locally (sign up codes) | http://localhost:8025 |
| API docs | http://localhost:8080/api/docs |

## Public homepage

`/` and `/business/<type>` work without login. Business types and their text are in `apps/web/src/components/home/businesses.ts`.
The images and videos in `apps/web/public/home` are generated by `scripts/generate_home_media.py`. Replace them with real photos and footage by keeping the file names or changing the paths.

## Roles and test data

| | Admin | Super admin |
|---|---|---|
| Moderation queue | Yes | Yes |
| Add and remove test data (Admin page, Test data tab) | Yes | Yes |
| Make or remove admins | No | Yes |
| Suspend staff | No | Admins only |

A super admin can only be created from the server: `python -m scripts.make_superadmin`. Test data is refused when
`APP_ENV=production` unless `ALLOW_TEST_DATA=true`. The original demo accounts from `make seed` are not test batches, so the Test data tab does not remove them.

Super admins can also add a large demo set (100 accounts, 10,000 posts) from the Test data tab. It downloads free photos from
Lorem Picsum (Unsplash License) and clips from test-videos.co.uk (Big Buck Bunny and Sintel, CC BY, Blender Foundation). Remove it before launch.

## Layout

| Path | Contents |
|---|---|
| `apps/web` | Next.js PWA. Mobile bottom tabs, tablet rail, desktop side nav. |
| `apps/backend` | FastAPI modular monolith, WebSocket gateway, MCP server, Celery workers. |
| `packages/api-types` | TypeScript types generated from the OpenAPI schema (`make types`). |
| `infra` | Docker Compose, nginx, Terraform, Helm, Argo CD, monitoring. |

## Common commands

```bash
make test       # backend tests against real Postgres and Redis
make test-web   # unit tests, type check and lint
make e2e        # Playwright at 360, 768 and 1280 px (stack must be running and seeded)
make lint       # ruff and mypy
make load       # k6 baseline
make types      # regenerate frontend types after an API change
make logs
make down
```

## Turning on optional features

Each is off, or degrades gracefully, until configured in `.env`:

| Feature | Setting | Without it |
|---|---|---|
| Claude features: assistant answers, image moderation, insights | `ANTHROPIC_API_KEY`. Set `AI_PROVIDER=anthropic` to use Claude for captions and writing help too. | The assistant quotes sources. Moderation uses rules only. |
| Google sign in | `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | The button is hidden. |
| Bot check on sign up | `TURNSTILE_SECRET`, `TURNSTILE_SITE_KEY` | Skipped. |
| Semantic search, writing help, photo captions | `AI_PROVIDER=cloudflare` with `CLOUDFLARE_ACCOUNT_ID` and `CLOUDFLARE_AI_TOKEN`. Runs on Cloudflare Workers AI, with no model on this server. Post text and photos go to Cloudflare. For photo captions, accept the Llama vision license once by sending `{"prompt": "agree"}` to `@cf/meta/llama-3.2-11b-vision-instruct`. | Keyword search still works. Composer hides suggestion chips. |
| Subtitles | Build with `UV_EXTRAS="--extra ai"`, then set `WHISPER_ENABLED` | No subtitles. |
| Malware scanning | `--profile av` and `CLAMAV_HOST=clamav` | Skipped. |
| Metrics dashboards | `--profile monitoring` | Metrics endpoint only. |
